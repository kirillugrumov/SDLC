## Описание проекта

«Лапа рядом» — адаптивная веб-система для координации волонтёрской помощи животным. Представители приютов публикуют проверенные заявки, волонтёры выбирают задачи и сообщают о выполнении, а координаторы подтверждают результат.

Первая версия рассчитана на один город. Денежные сборы, платежи, ветеринарная диагностика и нативные мобильные приложения не входят в MVP.
